## ADDED Requirements

### Requirement: Practice lab guides a complete OpenSpec change
The repository SHALL provide a hands-on practice lab that guides beginners through creating, specifying, validating, and optionally archiving an OpenSpec change.

#### Scenario: Beginner follows the practice lab
- **WHEN** a beginner follows the practice lab step by step
- **THEN** they can create a change, write proposal, specs, design, tasks, run validation, and understand when to archive

### Requirement: Practice lab uses a safe documentation exercise
The practice lab SHALL use a low-risk documentation exercise so beginners can learn the workflow without changing runtime behavior.

#### Scenario: Beginner practices safely
- **WHEN** a beginner completes the exercise
- **THEN** only documentation and OpenSpec artifacts are affected

### Requirement: Practice lab is discoverable from README
The repository SHALL link the practice lab from the main README.

#### Scenario: Reader starts from README
- **WHEN** a reader opens README.md
- **THEN** they can navigate to the practice lab document
