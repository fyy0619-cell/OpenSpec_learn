## Why

The README explains OpenSpec concepts, but beginners also need a hands-on lab that tells them exactly what to type and what files to create.

## What Changes

- Add a step-by-step OpenSpec practice lab under `docs/`.
- Link the practice lab from README.
- Add an active example change so learners can inspect how this documentation addition is specified.
