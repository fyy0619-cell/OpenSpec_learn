## Why

The repository currently only states that it is for learning OpenSpec, but it does not teach a beginner how OpenSpec works or how to operate a real project step by step.

## What Changes

- Add a beginner-friendly README that explains OpenSpec concepts, workflow, commands, and project operations.
- Add a complete example change so learners can inspect OpenSpec artifacts directly.
- Keep the example small and documentation-focused so it is easy to validate and understand.
