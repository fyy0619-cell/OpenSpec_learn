## ADDED Requirements

### Requirement: Roadmap recommends one resume-worthy project
The repository SHALL provide a detailed roadmap that recommends one resume-worthy project aligned with embedded systems, sensors, wireless communication, edge AI, and OpenSpec.

#### Scenario: Learner chooses a project direction
- **WHEN** the learner reads the roadmap
- **THEN** they can understand why the recommended project fits their background and career direction

### Requirement: Roadmap is directly executable
The roadmap SHALL provide step-by-step milestones, technical stack, architecture, testing metrics, and deliverables so the learner can execute the project without redesigning it from scratch.

#### Scenario: Learner follows the roadmap
- **WHEN** the learner follows the weekly plan
- **THEN** they can build an MVP and progressively extend it into a portfolio project

### Requirement: Roadmap includes resume and interview material
The roadmap SHALL include resume bullets and interview talking points for the recommended project.

#### Scenario: Learner prepares job applications
- **WHEN** the learner finishes the project
- **THEN** they can adapt the provided bullets and talking points for a resume or interview
